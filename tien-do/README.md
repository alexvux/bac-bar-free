# Thư mục tiến độ

Thư mục này ghi lại tiến độ làm game ngay trong repo, để bạn theo dõi trên GitHub mà không cần mở cửa sổ chat nào.

- [`STATUS.md`](STATUS.md): trạng thái hiện tại. Được cập nhật sau mỗi tính năng: đã xong gì, đang làm gì, tiếp theo là gì, cách chạy, link nhánh và PR.
- `01-…md`, `02-…md`…: ghi chú ngắn cho từng tính năng, theo thứ tự commit.
- [`anh-chup/`](anh-chup/) (khi có): ảnh chụp màn hình lúc tự chơi thử.

Đọc từ `STATUS.md` trước, rồi mở ghi chú từng bước nếu muốn biết chi tiết.
