# 11 — Deploy GitHub Pages

Deploy bản build tĩnh (`bun run build` → `dist/`) lên GitHub Pages bằng GitHub Actions.

Link chơi: https://alexvux.github.io/bac-bar-free/

Link `*.trycloudflare.com` là Cloudflare tunnel tạm: chỉ sống khi có máy đang chạy `cloudflared`. Pages thì ổn định, không cần bật máy.
